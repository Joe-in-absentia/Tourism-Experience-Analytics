# 📌 Project Overview

Travel recommendation systems help users discover attractions based on their preferences, travel style, and historical patterns.

This project builds a complete **Machine Learning-based Tourism Recommendation System** that can:

➡ Predict attraction ratings
➡ Predict visitor travel mode
➡ Recommend attractions using clustering techniques

The system uses:

* **XGBoost Regression**
* **XGBoost Classification**
* **K-Means Clustering**
* **Streamlit Dashboard**

# 🧠 Recommendation System

The recommendation engine groups similar attractions using **K-Means Clustering**.

Recommendations are generated based on:

➡ Continent
➡ Attraction Type
➡ Season
➡ Attraction Popularity
➡ Average Ratings
